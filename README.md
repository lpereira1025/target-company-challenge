<h1>Resolução de Desafios</h1>
Este projeto contém a solução de cinco desafios propostos, implementados em JavaScript. Abaixo, uma breve descrição de cada desafio:


<h2>1. Soma de uma sequência com laço while.

Um código que realiza a soma de números inteiros de 1 até 13 (variável INDICE), utilizando um laço while. O valor final da soma é 91.

<hr>

<h2>2. Verificação na Sequência de Fibonacci
  
Um programa que verifica se um número informado pertence à sequência de Fibonacci.
A sequência de Fibonacci começa com 0 e 1, e cada número subsequente é a soma dos dois anteriores.

Exemplo de uso:
Entrada: 21
Saída: 21 pertence à sequência de Fibonacci.

<hr>

<h2>3. Análise de Faturamento Diário
  
Dado um conjunto de dados de faturamento diário (em formato JSON), o programa calcula:

O menor valor de faturamento em um dia útil.
O maior valor de faturamento em um dia útil.
A quantidade de dias em que o faturamento diário foi superior à média mensal.

<hr>

<h2>4. Percentual de Faturamento por Estado
  
Com base no faturamento mensal detalhado por estado, o programa calcula o percentual de contribuição de cada estado no total mensal.

Exemplo de saída:

SP: 37.53%
RJ: 20.29%
MG: 16.16%
ES: 15.03%
Outros: 10.99%

<hr>

<h2>5. Inversão de String
Um programa que inverte os caracteres de uma string informada, sem utilizar funções prontas como reverse.

Exemplo de uso:
Entrada: "javascript"
Saída: "tpircsavaj"
